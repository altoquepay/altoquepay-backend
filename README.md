# altoquepay-backend

REST API of **AlToquePay**, a web application for small neighborhood businesses (corner stores, bakeries, butcher shops, hair salons and similar) to manage the credit they grant to their customers. It is built with FastAPI and consumed by the Angular web frontend, [altoquepay-frontend](https://github.com/altoquepay/altoquepay-frontend).

> **Status:** early development (`0.x`). Only the FastAPI project scaffold exists so far: a health check endpoint, its test and the tooling configuration.

## Tech stack

- Python 3.12 or newer
- FastAPI, served by Uvicorn, with Pydantic for validation
- OpenAPI documentation with Swagger UI, generated by FastAPI
- pytest and HTTPX for tests
- Ruff for linting and formatting

## Getting started

### Requirements

- Python 3.12 or newer

### Run in development

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

On fish, activate it with `source .venv/bin/activate.fish`; on Windows, with `.venv\Scripts\activate`.

Install the dependencies and start the development server:

```bash
pip install -r requirements.txt
fastapi dev app/main.py
```

The API starts on `http://localhost:8000` and reloads on file changes. The Swagger UI is available at `http://localhost:8000/docs`.

### Tests and linting

```bash
pytest
ruff check .
ruff format .
```
